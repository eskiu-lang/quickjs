## `<quickjs>`

JavaScript in an Eskiu program, over QuickJS (`<quickjs>`).

A JsRuntime owns the heap, the limits, the module loader and the host
functions; a JsContext is one global scope inside it. Scripts and ES modules
are evaluated in a context, and their values come back as JsValue handles:

```eskiu
*JsRuntime rt = js_runtime()?;
defer rt.release();
rt.set_fs_loader("scripts");
JsContext ctx = rt.context()?;
defer ctx.release();
JsValue engine = ctx.object();
engine.set_fn("log", 1, JsValue(*JsContext c, *JsArgs a) {
    printf("%s\n", a.str(0));
    return c.undefined();
});
ctx.set_global("engine", engine);
JsValue ns = ctx.eval_file("scripts/main.js")?;
ns.free();
JsValue r = ctx.call_global("onUpdate", &dt, 1)?;
r.free();
```

Ownership: every JsValue a function returns is owned by the caller and is freed
with free(), except the arguments a host function receives (JsArgs.at), which are
borrowed. Functions documented as "consuming" a value free it themselves.
release() on a runtime reports values that were never freed.

Fallible operations return a Result whose error is the JavaScript exception as
text: "Name: message" followed by the stack ("    at f (main.js:3:9)"). The
same exception, split into fields, stays in js_last_error() until the next one.

### JsFn

```eskiu
type JsFn = fn(*JsContext, *JsArgs)->JsValue;
```

A host function: it receives the calling context and its arguments and returns
the result, owned by the caller (usually made with the context's constructors).
Returning c.throw_error(msg) throws msg in the script; returning a value whose
kind is JS_EXCEPTION passes on the exception already pending.

### JsResolveFn

```eskiu
type JsResolveFn = fn(string, string, *String)->bool;
```

Resolves module `name` imported from module `base` (the importer's resolved name,
or "" for JsContext.import): appends the resolved name to out and returns true, or
returns false when the module does not exist.

### JsLoadFn

```eskiu
type JsLoadFn = fn(string, *String)->bool;
```

Appends the source of the resolved module `path` to out and returns true, or
returns false when it cannot be read.

### JsInterruptFn

```eskiu
type JsInterruptFn = fn()->bool;
```

Returns true to stop the running script, which then fails with
"InternalError: interrupted".

### JsRuntime

### JsRuntime_release

```eskiu
int64 JsRuntime_release(*JsRuntime self)
```

Frees the runtime, its host functions and loader. Every context must be released
first. Returns 0, or the number of JavaScript objects still referenced by values
that were never freed: the runtime's memory is then left allocated (QuickJS cannot
free a heap with live objects) and js_live_blocks() stays above 0.

### JsRuntime_set_memory_limit

```eskiu
void JsRuntime_set_memory_limit(*JsRuntime self, int64 bytes)
```

Caps the heap at `bytes` (0: no limit). An allocation past it fails the running
script with "InternalError: out of memory".

### JsRuntime_set_max_stack_size

```eskiu
void JsRuntime_set_max_stack_size(*JsRuntime self, int64 bytes)
```

Sets the JavaScript stack limit in bytes (0: no limit). Deep recursion past it
fails with "InternalError: stack overflow" instead of overflowing
the thread's stack, so it must stay below the stack of the thread that runs the
scripts (8 MiB on the main thread of macOS and Linux, 1 MiB on Windows).

### JsRuntime_update_stack_top


Takes the current stack position as the top of the JavaScript stack: call it
when the runtime moves to another thread.

### js_fs_resolve

